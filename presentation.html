대상과 문제

운동 부위와 기구를 함께 이해하기

이 제품이 돕고 싶은 사람

운동을 처음 시작하거나
기구 사용이 낯선 사람

부위와 기구를 연결해 보여주면 오늘 사용할 기구를 선택하기 쉬워진다는 제품 가설입니다.

사용 상황 예시 01
“등 운동은 어떤 기구로 하지?”

관심 있는 부위로 운동과 연결 기구를 찾습니다.

사용 상황 예시 02
“랫 풀다운은 어떻게 쓰지?”

기구 이름으로 찾고 기본 사용 안내를 확인합니다.

예시 문구이며 실제 사용자 인터뷰 인용이 아닙니다.사용자 조사와 효과 측정은 아직 진행하지 않았습니다.

  • 01

    부위로 찾기

    연결된 운동과 기구를 보여줍니다.

  • 02

    기구로 찾기

    이름과 별칭으로 검색합니다.

  • 03

    운동 상세

    사용 순서와 출처를 확인합니다.

현재 운동 3개 · 기구 3개 · 부위 분류 7개
어깨·팔·복부 운동은 미등록 상태입니다.

체스트 프레스 · 랫 풀다운 · 레그 프레스등록하지 않은 부위와 검색 결과 없음도 안내합니다.
운동 첫걸음04 / 05

사용 흐름

기구를 찾고, 사용법을 확인합니다

  1. 부위 선택 또는 기구 검색

    예: ‘등’을 고르거나 ‘랫풀다운’을 검색합니다.

  2. 연결된 기구와 운동 확인

    랫 풀다운 머신과 관련 운동을 살펴봅니다.

  3. 운동 상세에서 사용 안내 확인

    순서·주의점과 출처를 함께 읽습니다.

  4. 다른 운동으로 탐색 이어가기

    상세를 닫으면 현재 선택과 검색어가 유지됩니다.

안내 원문: ACE 체스트 프레스ACE 랫 풀다운ACE 레그 프레스전문가 검수·개인 적합성 확인 전 안내 초안
