# 운동 첫걸음

헬스장에서 오늘 운동할 부위와 기구를 찾고, 사용법과 추천 운동을 보는 초보자용 웹 앱이에요.

## 누구를 위한 앱인가

- 운동을 처음 시작하는 사람을 위한 앱이에요.
- 부위별로 어떤 기구를 써야 하는지 모르는 사람을 돕습니다.
- 기구 이름을 몰라도 부위나 별칭으로 찾을 수 있게 만들었어요.

## 할 수 있는 일

- **부위로 찾기:** 가슴, 등, 하체, 엉덩이, 어깨, 팔, 복부 중 하나를 고르면 연결된 운동과 기구가 나와요. 복부 운동은 아직 없어요.
- **기구로 찾기:** 한글·영어 이름이나 별칭(예: `랫풀다운`, `lat pulldown`)으로 기구를 찾아요. 공백만 넣고 검색하면 안내 문구가 나와요.
- **운동 사용법 보기:** 사용 순서, 주의할 점, 원문 출처를 볼 수 있어요.
- **오늘의 추천:** 쓸 수 있는 기구와 쉬고 싶은 부위를 고르면 운동을 최대 3개까지 추천해요. 추천한 이유도 함께 보여 줘요.
- **선택 기억:** 고른 화면, 부위, 검색어, 추천 조건이 브라우저에 저장돼요. 새로고침해도 그대로 남아요.

지금은 기구 6개와 운동 6개가 들어 있어요.

운동 안내는 출처 자료를 요약한 초안이고, 전문가 검수는 아직 받지 않았어요. 추천은 정해진 규칙으로 고른 결과라서 운동 처방이 아니에요. 무게, 세트, 횟수도 알려 주지 않아요.

## 사용 방법

1. **부위로 찾기**에서 운동하고 싶은 부위를 누릅니다.
2. 운동 카드의 **사용법 보기**를 눌러 사용 순서와 주의점을 읽습니다. 다 읽었으면 **닫기**나 `Esc`로 닫습니다.
3. 기구 이름으로 찾고 싶으면 **기구로 찾기**에서 이름을 입력합니다.
4. **오늘의 추천**에서 쓸 수 있는 기구를 확인했는지 고릅니다. 기구를 잘 모르면 **아직 모르겠어요**를 고르고 기구부터 찾아봅니다.
5. 쓸 수 있는 기구를 체크합니다. 필요하면 좋아하는 부위와 쉬고 싶은 부위도 고릅니다.
6. **추천 받기**를 누르고, 추천 카드의 이유와 사용법을 확인합니다.

## 실행 방법

1. 이 폴더를 내려받습니다.
2. `index.html`을 브라우저로 엽니다. 파일을 더블클릭해도 되고, 터미널에서 열어도 됩니다.
   - macOS: `open index.html`
   - Windows 명령 프롬프트: `start index.html`
3. `index.html`, `styles.css`, `catalog.js`, `recommend.js`, `app.js`는 같은 폴더에 두세요.

설치나 서버 없이 바로 열립니다. 내려받지 않고 [배포 주소](https://seongj-un.github.io/undong-plan/)로 열어도 돼요. 개발용 API 서버도 있지만 화면을 쓰는 데는 필요 없어요. 자세한 내용은 [API 명세서](docs/api-spec.md)를 보세요.

## 확인 방법

점검표는 [docs/checklist.md](docs/checklist.md)에 있어요. 결과 칸은 사람이 직접 채웁니다.

지금 점검표는 일정 앱 양식(일정 추가·완료·삭제)으로 쓰여 있어요. 그래서 이 앱에서는 아래 핵심만 먼저 확인하세요.

- **콘솔 오류 없음:** 개발자 도구의 Console에 오류가 없어야 해요. (점검표 공통-1)
- **빈 입력 안내:** 기구 검색창에 공백만 넣고 검색하면 안내 문구가 나와야 해요.
- **빈 목록 안내:** 복부처럼 운동이 없는 부위를 고르면 안내 문구가 나와야 해요.
- **저장 유지:** 고른 내용이 새로고침하거나 창을 다시 열어도 남아 있어야 해요.
- **추천:** 고른 기구로 할 수 있는 운동만, 이유와 함께 나와야 해요.

## 데이터 저장 안내

- 고른 내용은 이 브라우저의 `localStorage`에만 저장돼요. 서버로 보내지 않아요.
- 다른 브라우저에서 열면 저장한 내용이 보이지 않아요.
- 주소가 다르면 저장 공간도 달라요. 예를 들어 파일로 연 화면과 배포 주소로 연 화면은 서로 내용이 달라요.
- 폴더 위치를 옮기면 파일 주소가 바뀌어서 이전 내용이 안 보일 수 있어요.
- 시크릿 창에서는 창을 닫으면 저장 내용이 지워져요.
- 실제 개인 정보는 넣지 말고, 연습용 가상 데이터만 입력하세요.

## 만든 과정

- **프롬프트 엔지니어링:** 요청을 "무엇을, 어디까지, 어떻게 확인할지"로 나눠 적었어요. 확정한 것과 아직 정하지 않은 것을 구분해 AI에게 맡겼어요.
- **하네스 엔지니어링:** [AGENTS.md](AGENTS.md)에 역할, 실행 방법, 확인 절차, 공개 전 규칙을 적었어요. 그래서 AI가 매번 같은 규칙으로 일했어요.
- **루프 엔지니어링:** 브라우저로 확인하고, 실패를 기록하고, 고친 뒤 다시 확인하기를 반복했어요. 같은 문제는 3번까지만 고쳤고, 결과는 [loop-log.md](loop-log.md)에 남겼어요.
