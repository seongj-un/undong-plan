# 오늘의 운동 부위와 기구 추천 기획서

초보자가 ‘어느 부위를 운동할지’와 ‘어느 기구를 사용할지’를 함께 이해하도록 안내한다. 첫 버전은 로그인 없는 부위·기구 안내와 규칙 기반 추천으로 확정했으며, 아래 세부 기능과 추천 규칙은 초안이다.

작성일: 2026-09-30 · 문서 상태: 초안 v0.2 · 범위 결정: [프로젝트 개요서](project-overview.md)

## 현재 구현 범위

사용자의 ‘가장 가벼운 기능 3개 구현’ 요청에 따라 F01·F02·F03을 [로컬 정적 화면](../index.html)으로 먼저 구현했다. 이후 2026-09-30 ‘지금 docs 폴더에 있는데로 구현 완료 해줘’, ‘전부 구현해 서브 에이전트 이용해서’ 요청에 따라 F04~F06을 같은 로컬 화면에 구현하고(추천 계산은 `recommend.js`), [API 명세서](api-spec.md)의 API 6개를 `server/server.js`로 구현했다. 화면은 서버 API를 호출하지 않는다.

| 기능 | 현재 화면 동작 | 현재 데이터 제약 |
| --- | --- | --- |
| F01 | 전체·7개 부위 선택, 연결 운동과 기구 표시, 미등록 부위 안내 | 운동 3개, 출처 대상 부위로 탐색 |
| F02 | 이름·한글/영문 별칭 부분 검색, 상세, 초기화, 빈 결과 | 기구 3개, 사진 미제공 |
| F03 | 상세에서 부위·기구·사용 순서·주의점·출처·확인일 표시 | 한국어 요약 초안, 전문가 검수 미완료 |
| F04 | 기구 확인 여부(필수)·사용할 수 있는 기구·선호/제외 부위·최대 추천 수 입력, 아래 추천 규칙으로 운동 카드 표시 | 검수 전 초안 3개를 미리보기 후보로 사용(아래 예외) |
| F05 | 카드마다 주 사용 부위, 보조 부위, 사용 기구, 추천 이유, 사용법 보기 | 보조 부위 미정이면 확인한 범위만 이유에 표시 |
| F06 | 입력 수정 필요, 기구 확인 필요(기구로 찾기 연결), 기구 없음, 조건에 맞는 후보 없음, 일부만 추천을 구분 | 조건을 자동으로 완화하지 않음 |

로컬 추천 미리보기 예외(기본안 적용·사용자 확인 대기): 추천 규칙 4는 검수 완료 운동만 후보로 삼는다. 현재 카탈로그에는 검수 완료 운동이 없어 규칙 4만 적용하면 기구를 확인해도 항상 후보가 없다. 로컬 화면은 검수 전 초안(`review: null`)을 미리보기 후보로 사용하고, 카드마다 ‘검수 전 초안’과 운동 처방이 아니라는 안내를 표시한다. 서버 API는 규칙 4를 그대로 적용해 검수 완료 운동만 후보로 쓴다. 서버·공개 카탈로그의 정책 변경이 아니다.

보조 부위 미정 처리(기본안 적용·사용자 확인 대기): 로컬 초안의 `secondaryBodyPartIds`는 `null`이므로 규칙 5의 제외 판단에 주 사용 부위와 출처의 대상 부위(`sourceBodyPartIds`)를 함께 쓴다. 엉덩이를 제외하면 레그 프레스가 빠진다. 규칙 6의 선호 부위는 주 사용 부위에만 적용하므로, F01에서 엉덩이를 고르면 레그 프레스가 보이지만 선호 부위를 엉덩이로 하면 추천 후보가 없다. 추천 이유는 제외 부위가 주 사용 부위와 출처의 대상 부위에 없다는 것까지만 말하고 보조 부위는 미정으로 표시한다.

추천 입력과 결과는 저장하지 않는다. 탭을 오가도 현재 입력은 유지하며, 새로고침하면 빈 입력으로 시작한다.

검색 입력은 최대 50자이며 앞뒤 공백을 제거하고 영문 대소문자를 구분하지 않는다. 빈 입력은 전체 목록으로 처리하며, Enter 입력 시 페이지를 이동하거나 새로고침하지 않는다. 검색과 부위 선택은 탐색 방식 전환·상세 닫기 후 유지한다. 새로고침 시 전체 목록으로 시작하며 저장하지 않는다.

운동 카드의 주 사용 부위는 화면 분류 초안이다. 보조 부위는 확인되지 않아 `null`로 두고 ‘미정 · 전문가 검수 대기’를 표시한다. 별도의 `sourceBodyPartIds`는 원문 대상 부위를 표현한다. 레그 프레스는 원문에 하체·엉덩이가 모두 있어 두 부위에서 탐색 가능하다. 이것이 주·보조 부위의 생리학적 검수 완료를 의미하지는 않는다.

현재 안내 초안은 서버의 검수 완료 공개 카탈로그와 별도다. 서버는 검수 완료 운동만 공개·추천하며 현재 해당 운동은 0개다. 서버 추천을 실제로 제공하려면 콘텐츠 검수 담당자와 공개 가능한 데이터를 확정해야 한다. 사진은 권한 확인 전까지 텍스트로 대체한다.

## 사용자와 대표 시나리오

핵심 사용자는 운동 부위와 기구 이름을 모르는 사람이다. 헬스장에 있다는 이유만으로 기구 이름을 입력할 수 있다고 가정하지 않는다.

대표 시나리오: 사용자는 기구 사진과 별칭을 보고 사용 가능한 기구를 선택한다. 오늘 제외할 부위가 있으면 선택하고 추천을 요청한다. 결과에서 운동 부위, 기구 이름과 선택 이유를 확인한 뒤 상세 안내를 읽는다. 실제 사용자 조사 전의 시나리오 제안이다.

| 추천 조건 | 사용 가능한 기구, 선호 부위, 제외 부위 선택 | 필수 항목과 선택 항목 구분 |

## 추천 입력과 결과 제안

| 입력 | 필수 여부 | 의미 |
| --- | --- | --- |
| 기구 확인 상태 | 필수 | 사용 가능한 기구를 확인했는지 여부 |
| 사용 가능한 기구 목록 | 필수 | 확인한 기구의 식별자 배열 |
| 선호 부위 | 선택 | 선택한 부위의 운동만 추천하는 필터, 미선택 시 자동 선택 |
| 제외 부위 | 선택 | 오늘 추천에서 제외하려는 부위 |
| 최대 추천 수 | 선택 | 1~3개, 기본 3개 |

제외 부위에는 최근 운동한 부위 등을 사용자가 직접 넣을 수 있다. 시스템이 기록 없이 최근 운동을 추정하거나 회복 완료 여부를 판단하지 않는다. 통증·질환을 입력받아 치료용 운동을 추천하는 기능은 초안 범위에 없다.

결과는 운동별 안내 카드로 구성한다. 각 카드에 주 사용 부위, 보조 부위, 기구, 추천 이유와 상세 링크를 표시한다. 개인에게 적합한 무게·횟수·세트는 이번 초안의 추천 결과에 넣지 않는다.

## 추천 규칙 제안

이 절은 구현을 위한 제품 규칙 제안이며, 의학적 운동 처방이나 검증된 개인별 운동 계획이 아니다.

1. 입력 형식과 식별자를 검증한다. 선호 부위와 제외 부위가 겹치면 입력 수정을 안내한다.
2. 기구가 미확인이면 `needs_equipment_confirmation`을 반환하고 추천 카드는 만들지 않는다.
3. 확인한 기구가 없으면 `no_candidates`를 반환한다. 미확인과 확인 후 없음은 구분한다.
4. 공개 가능한 검수 완료 초보자용 운동만 후보로 삼는다. 필요한 기구가 모두 사용 가능해야 한다. 로컬 화면의 미리보기 예외는 [현재 구현 범위](#현재-구현-범위)를 참고한다.
5. 제외 부위가 주 사용 부위 또는 보조 부위에 포함된 운동은 제거한다. 보조 부위가 미정(`null`)인 로컬 초안은 출처의 대상 부위를 대신 적용한다.
6. 선호 부위를 선택했다면 주 사용 부위가 선호 부위에 포함된 운동만 남긴다. 다른 부위로 자동 대체하지 않는다.
7. 후보를 주 사용 부위별로 묶는다. 부위는 `chest`, `back`, `legs`, `glutes`, `shoulders`, `arms`, `core` 순서, 각 부위의 운동은 식별자 오름차순으로 정렬한다.
8. 각 부위에서 한 개씩 순회하여 최대 추천 수만큼 선택한다. 남는 자리가 있으면 같은 순서로 다음 운동을 선택한다. 중복 운동은 반환하지 않는다.
9. 추천 수 충족 시 `recommended`, 일부 후보만 존재하면 `partial`, 후보가 없으면 `no_candidates`를 반환한다. 조건을 임의로 완화하지 않는다.

7~8번은 재현 가능한 초안을 위한 정렬 규칙이며 특정 부위의 건강상 우선순위를 뜻하지 않는다. 입력과 카탈로그 버전이 같으면 결과가 같다. 같은 조건으로 다시 요청한다고 결과를 무작위로 변경하지 않는다.

‘오늘’이라는 문구만으로 매일 다른 부위나 연속 운동의 안전성을 보장하지 않는다. 날짜별 변경·회복 판단·주간 계획이 필요하면 별도 요구사항과 콘텐츠 검토를 진행한다.

## 부위와 기구 정보 제안

분류 식별자는 `chest` 가슴, `back` 등, `legs` 하체, `glutes` 엉덩이, `shoulders` 어깨, `arms` 팔, `core` 복부다. 실제 공개할 부위와 기구 개수는 미정이다. 카탈로그에 운동이 없는 부위를 추천하지 않는다.

아래는 실재하는 운동과 기구의 연결 예시다. 서비스 식별자는 초안에서 부여한 값이며 외부 기관의 식별자가 아니다.

| 운동 예시 | 기구 예시 | 부위 연결 근거 |
| --- | --- | --- |
| 앉아서 체스트 프레스 | 체스트 프레스 머신 | ACE는 가슴과 웨이트 머신으로 분류 |
| 앉아서 랫 풀다운 | 랫 풀다운 머신 | ACE는 등과 웨이트 머신으로 분류 |
| 앉아서 레그 프레스 | 레그 프레스 머신 | ACE는 엉덩이·허벅지와 웨이트 머신으로 분류 |

근거: [ACE 초보자 운동 목록](https://www.acefitness.org/resources/everyone/exercise-library/experience/beginner/?page=5). 이 분류는 모든 사용자에게 해당 운동이 적합하다는 보증이 아니다.

운동 데이터에는 식별자, 한국어 이름, 주 사용 부위, 보조 부위, 필요한 기구, 난이도, 사용 안내, 주의사항, 출처와 검수 정보를 둔다. 기구 데이터에는 이름, 별칭, 설명과 사진의 출처·사용 권한 정보를 둔다. 저장 기술은 미정이다.

## 콘텐츠 작성과 검수 제안

기구별 사용법은 검증 가능한 자료와 해당 기구 안내를 확인해 작성한다. 머신 모델이 다르면 조절 방법이 달라질 수 있으므로 확인하지 않은 조작 방법을 확정하지 않는다. 콘텐츠 검수 담당자와 검수 방법은 사용자 결정이 필요하다.

NHS는 운동을 천천히 시작하고 반복 수를 점진적으로 늘리도록 안내한다. 상세 안내 작성 시 이 원칙을 참고한다. [NHS Strength exercises](https://www.nhs.uk/live-well/exercise/strength-exercises/)

사진·영상은 출처와 사용 권한을 확인한 자료만 등록하는 방향을 제안한다. 공개된 웹 자료의 사진을 곧바로 서비스에 재사용할 수 있는지는 현재 알 수 없다. 이 문서에는 실제 사진이나 영상을 수집하지 않았다.

| 상황 | 기대 동작 |
| --- | --- |
| 기구 이름을 모름 | 사진과 별칭으로 기구를 탐색한 뒤 선택 |
| 기구를 아직 확인하지 않음 | 미확인 안내와 기구 찾기 화면 제공 |
| 확인했지만 사용할 기구가 없음 | 후보 없음 안내, 없는 기구를 추천하지 않음 |
| 제외 부위가 보조 부위에도 포함됨 | 해당 운동을 후보에서 제거 |
| 선호 부위와 제외 부위가 겹침 | 입력 오류 표시 |
| 후보가 요청 수보다 적음 | 있는 후보만 반환하고 일부 추천임을 표시 |
| 조회 결과가 없음 | 빈 목록과 조건 변경 안내 |
| 네트워크 또는 서버 오류 | 입력을 유지하고 재시도 제공 |
| 사진이 제공되지 않음 | 텍스트 설명 표시, 사진을 확인된 자료처럼 표시하지 않음 |

검수 완료 운동이 없는 경우 추천을 제공하지 않는다. 서버 API는 이 원칙대로 기구를 확인한 추천 요청에 현재 `no_candidates`를 반환한다. 로컬 화면만 위 미리보기 예외로 검수 전 초안을 ‘검수 전 초안’ 표시와 함께 보여 준다. 현재 탐색 화면의 한국어 사용법은 아래 개별 출처에서 확인한 내용의 요약 초안이다. 실제 사진 확보와 기구·운동 데이터의 전문 검수는 미완료다.

현재 안내 출처 (확인일 2026-09-30):

- [ACE · Seated Chest Press](https://www.acefitness.org/resources/everyone/exercise-library/188/seated-chest-press/): 가슴·웨이트 머신 분류, 좌석 높이와 손목·어깨 유지, 미는 동작과 복귀 안내.
- [ACE · Seated Lat Pulldown](https://www.acefitness.org/resources/everyone/exercise-library/158/seated-lat-pulldown/): 등·웨이트 머신 분류, 허벅지 패드·몸통 유지와 바를 당기고 복귀하는 안내.
- [ACE · Seated Leg Press](https://www.acefitness.org/resources/everyone/exercise-library/154/seated-leg-press/): 엉덩이·허벅지·웨이트 머신 분류, 등·발뒤꿈치 지지, 발판을 밀고 복귀하는 안내.

## 추후 검증 제안

초보자가 부위와 기구를 찾는 데 걸리는 시간, 추천 결과에서 운동 상세를 확인하는 비율, 후보 없음 발생 비율을 검토 지표로 제안한다. 목표 수치와 분석 도구는 미정이며 도구 도입 전 사용자에게 질문한다.

외부 자료 확인일: 2026-09-30. 사용자 결정 질문은 [프로젝트 개요서](project-overview.md)에 모아 두었다.
