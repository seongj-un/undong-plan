## 회귀 점검표

| 번호 | 항목 | 이렇게 확인한다 | 통과 조건 | 결과 |
| --- | --- | --- | --- | --- |
| 공통-1 | 콘솔 오류 없음 | 개발자 도구의 Console을 열고 기존 로그를 지운다. 앱을 새로고침한 뒤 아래 ①부터 ⑤-3까지 순서대로 조작한다. 창을 다시 연 뒤에도 Console을 확인한다. | 앱 로딩과 각 조작에서 애플리케이션 오류가 발생하지 않는다. | |
| ① | 추가 | 빈 목록에서 제목 입력칸에 `가상 일정 A`를 입력하고 추가 버튼을 한 번 누른다. | `가상 일정 A`가 목록에 정확히 한 개 추가되고 미완료 상태로 보인다. | |
| ② | 완료 표시(다시 누르면 해제) | 미완료인 `가상 일정 A` 한 개가 있는 상태에서 해당 일정의 완료 표시를 한 번 누른다. 줄 긋기를 확인한 뒤 같은 완료 표시를 한 번 더 누른다. | 첫 클릭 후 완료 상태와 줄 긋기가 표시된다. 두 번째 클릭 후 줄 긋기가 사라지고 미완료 상태로 돌아온다. 제목과 일정 개수는 그대로다. | |
| ③ | 가운데 일정 삭제 | 빈 목록에서 `가상 일정 A`, `가상 일정 B`, `가상 일정 C`를 차례로 추가한다. 가운데에 있는 `가상 일정 B`의 삭제 버튼만 한 번 누른다. | B만 사라지고 A와 C 두 개가 그 순서로 남는다. 남은 일정의 제목과 완료 상태는 바뀌지 않는다. | |
| 공통-2 | 빈 목록 안내 | `가상 일정 A` 한 개만 있는 목록에서 A의 삭제 버튼을 한 번 누른다. | 일정 항목이 하나도 남지 않고, 일정이 없다는 안내 문구가 보인다. | |
| ④-1 | 빈 제목 | 빈 목록에서 제목 입력칸의 내용을 모두 지워 빈 문자열로 만든 뒤 추가 버튼을 한 번 누른다. | 목록은 빈 상태로 유지되고 입력칸 근처에 한국어 안내 문구가 보인다. 경고창은 뜨지 않는다. | |
| ④-2 | 공백만 입력 | 빈 목록에서 제목 입력칸의 내용을 모두 지운다. 스페이스바를 정확히 세 번 눌러 공백 세 개만 입력한 뒤 추가 버튼을 한 번 누른다. | 목록은 빈 상태로 유지되고 입력칸 근처에 한국어 안내 문구가 보인다. 경고창은 뜨지 않는다. | |
| ④-3 | 정상 제목 | 빈 목록에서 공백 세 개만 입력하고 추가 버튼을 눌러 안내 문구를 띄운다. 입력칸을 모두 지운 뒤 `가상 일정 A`를 입력하고 추가 버튼을 한 번 누른다. | `가상 일정 A`가 정확히 한 개 추가되고 빈 제목 안내 문구가 사라진다. | |
| ⑤-1 | 추가 유지 | 빈 목록에서 `가상 일정 A`, `가상 일정 B`, `가상 일정 C`를 차례로 추가한다. 같은 브라우저에서 현재 페이지를 새로고침한다. | A, B, C 세 개가 같은 순서와 제목으로 남고 모두 미완료 상태다. | |
| ⑤-2 | 완료·삭제 유지 | ⑤-1에서 만든 미완료 A, B, C 목록에서 B의 완료 표시를 한 번 누르고 C의 삭제 버튼을 한 번 누른다. 같은 페이지를 새로고침한다. | A와 B만 그 순서로 남는다. A는 미완료, B는 완료 상태이며 B의 줄 긋기가 유지된다. C는 다시 나타나지 않는다. | |
| ⑤-3 | 창 다시 열기 | ⑤-2의 A 미완료·B 완료·C 삭제 상태에서 앱이 열린 브라우저 창을 닫는다. 같은 브라우저로 새 창을 열고 이전과 정확히 같은 앱 주소를 연다. | A와 B만 그 순서로 보인다. A는 미완료, B는 완료 상태와 줄 긋기를 유지한다. C는 다시 나타나지 않는다. | |
